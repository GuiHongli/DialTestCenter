### 2. 工具类增强

#### DatabaseHelper 扩展
新增方法（共 15 个新方法）：

**执行机操作：**
- `get_executor_by_id()` - 按 ID 查询执行机
- `get_all_executors()` - 查询所有执行机
- `update_executor_status()` - 更新执行机状态

**UE 操作：**
- `get_ue_by_serial()` - 按序列号查询 UE
- `get_ues_by_executor()` - 查询执行机的所有 UE
- `count_ues_by_executor()` - 统计执行机的 UE 数量
- `delete_ue_by_msisdn()` - 删除指定 UE
- `delete_ues_by_executor()` - 删除执行机的所有 UE

**用户操作：**
- `get_agent_user()` - 查询 Agent 用户信息
- `ensure_agent_user_exists()` - 确保 Agent 用户存在

**测试数据管理：**
- `cleanup_test_data()` - 清理测试数据

#### Assertions 扩展
新增断言方法（共 8 个新方法）：

**HTTP 断言：**
- `assert_status_code_in()` - 断言状态码在列表中
- `assert_json_field_equals()` - 断言 JSON 字段值
- `assert_json_has_fields()` - 断言包含所有字段

**业务断言：**
- `assert_executor_status()` - 断言执行机状态
- `assert_ue_exists()` - 断言 UE 存在
- `assert_ue_field()` - 断言 UE 字段值

**WebSocket 断言：**
- `assert_message_type()` - 断言消息类型
- `assert_websocket_data_has_fields()` - 断言消息数据字段

## 使用指南

### 快速运行测试

```bash
# 1. 安装依赖
cd test
pip install -r requirements.txt

# 2. 配置环境
cd executormanagement
cp env.example .env
# 编辑 .env 文件，设置必要的配置

# 3. 运行测试
chmod +x run_tests.sh
./run_tests.sh                    # 运行所有测试
./run_tests.sh api                # 仅运行 API 测试
./run_tests.sh ws                 # 运行 WebSocket 测试
./run_tests.sh sc01               # 运行 SC-01 场景测试
```

### 启用 WebSocket 测试

```bash
# 设置环境变量
export EXEC_WS_ENABLE=1
export EXEC_AGENT_NTLM_HASH=<your_ntlm_hash>

# 运行测试
python -m pytest test_sc01_register_auth.py -v
```

### 生成测试报告

```bash
# HTML 报告
python -m pytest --html=report.html --self-contained-html

# 覆盖率报告
python -m pytest --cov=. --cov-report=html
```

## 测试设计原则

### 1. 独立性
- 每个测试用例独立运行
- 不依赖其他测试的执行顺序
- 测试数据使用前缀隔离

### 2. 可重复性
- 测试结果可重现
- 自动清理测试数据
- 环境配置标准化

### 3. 可维护性
- 清晰的测试结构
- 丰富的注释和文档
- 工具类复用

### 4. 完整性
- 覆盖核心功能
- 包含正向和负向测试
- 验证数据库状态

### 5. 性能意识
- 包含性能基准测试
- 响应时间断言
- 资源使用监控（可扩展）
