# 软件包管理模块软件实现设计文档

## 1 需求重述

### 1.1 需求背景
拨测脚本执行时，其依赖的软件包必须提前安装好，因此需要提前管理需要的软件包。此次需要的软件包主要为手机上的APP安装包，涉及Android和iOS系统。

### 1.2 需求功能介绍
软件包管理模块提供对拨测脚本依赖软件包的完整生命周期管理，包括上传、下载、编辑、删除和查询功能，支持多种上传方式和权限控制。

### 2.2 功能点1：软件包上传功能

#### 详细描述

**数据库表设计：**
```sql
CREATE TABLE software_package (
    id BIGSERIAL PRIMARY KEY,
    software_name VARCHAR(255) NOT NULL UNIQUE,
    description TEXT,
    file_content BYTEA NOT NULL,
    file_sha256 VARCHAR(64) NOT NULL,
    file_size BIGINT NOT NULL
);

CREATE INDEX idx_software_package_name ON software_package(software_name);
```

**权限控制：**
- 仅ADMIN和OPERATOR角色有上传权限
- 通过用户角色表验证用户权限

**上传方式支持：**
1. 上传ZIP包（包含多个安装包）- 解压后按单个软件包存储
2. 上传单个安装包
3. 上传多个安装包

**文件大小限制：**
- 单个文件：≤100MB
- ZIP包：≤1GB

**算法流程图：**
```plantuml
@startuml
start
:接收上传请求;
:验证用户权限;
if (用户权限验证通过?) then (是)
  :解析上传文件;
  if (文件类型?) then (ZIP包)
    :解压ZIP包;
    :遍历解压文件;
    :验证每个文件大小≤100MB;
    if (文件大小验证通过?) then (是)
      :批量处理解压文件;
      :为每个文件计算SHA256;
      :为每个文件检查软件名称唯一性;
      if (存在重复软件名称?) then (是)
        :提示用户是否覆盖;
        if (用户选择覆盖?) then (是)
          :删除原文件记录;
          :保存所有新文件;
        else (否)
          :返回错误信息;
        endif
      else (否)
        :直接保存所有文件;
      endif
    else (否)
      :返回文件过大错误;
    endif
  elseif (单个文件) then
    :验证文件大小≤100MB;
    if (文件大小验证通过?) then (是)
      :计算文件SHA256;
      :检查软件名称唯一性;
      if (软件名称已存在?) then (是)
        :提示用户是否覆盖;
        if (用户选择覆盖?) then (是)
          :删除原文件记录;
          :保存新文件;
        else (否)
          :返回错误信息;
        endif
      else (否)
        :直接保存文件;
      endif
    else (否)
      :返回文件过大错误;
    endif
  else (多个文件)
    :遍历每个文件;
    :验证每个文件大小≤100MB;
    if (所有文件大小验证通过?) then (是)
      :批量处理文件;
      :计算每个文件SHA256;
      :检查软件名称唯一性;
      if (存在重复软件名称?) then (是)
        :提示用户是否覆盖;
        if (用户选择覆盖?) then (是)
          :删除原文件记录;
          :保存新文件;
        else (否)
          :返回错误信息;
        endif
      else (否)
        :直接保存文件;
      endif
    else (否)
      :返回文件过大错误;
    endif
  endif
  :记录操作日志;
  :返回成功响应;
else (否)
  :返回权限不足错误;
endif
stop
@enduml
```

### 2.3 功能点2：软件包下载功能

#### 详细描述

**权限控制：**
- ADMIN、OPERATOR、EXECUTOR角色有下载权限
- 支持批量下载

**下载流程：**
```plantuml
@startuml
start
:接收下载请求;
:验证用户权限;
if (用户权限验证通过?) then (是)
  if (下载类型?) then (单个文件)
    :根据软件名称查询文件;
    if (文件存在?) then (是)
      :返回文件流;
    else (否)
      :返回文件不存在错误;
    endif
  else (批量下载)
    :解析下载文件列表;
    :验证所有文件存在;
    if (所有文件存在?) then (是)
      :打包为ZIP;
      :返回ZIP文件流;
    else (否)
      :返回文件不存在错误;
    endif
  endif
  :记录操作日志;
else (否)
  :返回权限不足错误;
endif
stop
@enduml
```

#### 详细描述

```plantuml

  :保存新软件包;
```

### 2.8 功能点7：操作记录功能

#### 详细描述

**操作记录说明：**
所有软件包管理操作（上传、下载、编辑、删除、覆盖）的操作记录由操作记录模块统一管理，包括：
- 操作时间
- 操作用户
- 操作类型
- 操作对象
- 操作结果

软件包管理模块通过调用操作记录模块的接口记录操作信息。
